# ABookPlayer.vxp
A feature-rich audio file player for MRE (MediaTek's MAUI Runtime Environment) platform. This code is for use in https://github.com/XimikBoda/TinyMRESDK
The application is made using AI, credited in the app's "About" section (Gemini 3.8 Flash; Gemini 4 Hydrogen).
**Instructions:** put the *.vxp file in the same folder as the songs, you want to play.

Features:
* it can play MIDI, AMR, MP3, WAV, AAC files, if the phone supports them, starting from any point with down to a second precision;
* can read MIDIs almost infinitely long, because there is no size limit on those, unlike in regular apps;
* a color scheme framework is implemented along with custom UI system;
* sorting, filtering, looping tracks in variety of ways;
* quicker scrolling using */# keys or by entering entry number using dial keys;
* karaoke mode with various screensavers and LRC subtitle file support (starting with ver. 1.1);
* ID3 tag support (starting with ver. 1.1);
* volume controls via menu or hardware keys (starting with ver. 1.1);
* in-app help (starting with ver. 1.2).
